Elementum — Front-end

This is a small Vite + React demo site for the "Elementum" front-end prototype. It includes a single-page layout, decorative SVGs, placeholder images, and a focused CSS theme (see src/App.css).

What’s included

- Source: src/ (App.jsx, components/)
- Main stylesheet: src/App.css
- Reference image: Elementum.jpg
- Build output: dist/ (generated by npm run build)

Prerequisites

- Node.js 16+ (Node 18+ recommended)
- npm (bundled with Node) or yarn

Setup

1. Install dependencies

```
npm install
```

2. Run the development server

```
npm run dev
```

Open http://localhost:5173 (or the URL shown in the terminal).

3. Create a production build

```
npm run build
```

4. Preview the production build locally

```
npm run preview
```

GitHub — quick upload steps
If you want to push this folder to a new GitHub repository, run the following from the project root. Replace <your-user> and <repo> with your details.

```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin git@github.com:<your-user>/<repo>.git
git push -u origin main
```

If you prefer HTTPS:

```
git remote add origin https://github.com/<your-user>/<repo>.git
git push -u origin main
```

Deploy to GitHub Pages (optional)
Two straightforward options:

- Use the gh-pages package (single-branch deploy).

```
npm install --save-dev gh-pages
# add "deploy" script to package.json: "deploy": "gh-pages -d dist"
npm run build
npm run deploy
```

- Use GitHub Actions to build & publish from main automatically (recommended for CI workflows). Create a workflow file under .github/workflows/ to build and deploy dist/.

Notes & recommendations

- Replace placeholder images used in App.jsx with your real assets (recommended path: public/images/ or src/assets/).
- Fonts are imported in src/App.css. If you want exact typography from the reference, swap the font-family in :root and adjust sizes in src/App.css.
- Elementum.jpg is included in the project root and used for reference/design.

Troubleshooting

- If the dev server fails to start, ensure Node and npm versions meet the prerequisites and remove node_modules + reinstall:

```
rm -rf node_modules package-lock.json
npm install
```
